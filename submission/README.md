# Submission Starter

Read the complete [assignment](../assignment.md). The supplied `reserve.sql`, `confirm.sql` and `cancel.sql`
are intentionally defective. Keep their originals in an untouched package copy. Repair your working copies.

Write your cases in `tests.sql`. `report.md` is an optional outline; another readable report format is accepted.
Submit four SQL files and one report in a ZIP whose root is `assignment-3/`. Include `AI_DISCLOSURE.md` when
required by the brief's policy. Optional `assets/` can hold images included in the report.
Do not submit this README, Docker/runtime files, database dumps or private course materials.

Check that a TA can follow your operation-file/order-ID map, reproduce the original counterexamples separately,
replay your repairs from equivalent starting states and inspect your assertions and concurrent evidence.
